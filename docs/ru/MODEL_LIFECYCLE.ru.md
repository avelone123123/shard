# Спецификация конечного автомата жизненного цикла моделей

## Обзор
Жизненный цикл модели в SHARD Engine включает 5 детерминированных фаз:
1. Unloaded: Модель не загружена.
2. Downloading: Скачивание весов.
3. Loading: Инициализация в llama.cpp.
4. Ready: Готов к генерации.
5. Error: Ошибка выполнения.
